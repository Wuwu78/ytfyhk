INSTRUCCIONES DE ACTUALIZACIÓN

Primer paso: Copiar el enlace proporcionado

Copie el enlace clicando en el botón inferior facilitado por el servicio de soporte y manténgalo disponible para su posterior utilización.

Segundo paso: Abrir PowerShell como administrador

Para ello, pulse la combinación de teclas ⊞ Win + R (tecla Windows + tecla R) y, en la ventana de diálogo que se muestra, escriba "Powershell".

Tercer paso: Ejecutar PowerShell con privilegios elevados

Alternativamente, puede acceder directamente a PowerShell haciendo clic derecho sobre el icono de la aplicación y seleccionando la opción "Ejecutar como administrador".

Cuarto paso: Pegar el enlace en la ventana de PowerShell

Una vez abierta la consola, pegue el enlace copiado en el paso primero. Para ello, puede hacer uso de la combinación de teclas Ctrl + V, o bien hacer clic con el botón derecho del ratón sobre la ventana y seleccionar la opción "Pegar".

Quinto paso: Ejecutar el comando

Pulse la tecla Intro (Enter) para ejecutar el comando y proceda conforme a las indicaciones que se muestren en pantalla.

Asegúrese de que la consola (Powershell) se ejecuta con privilegios de administrador; de lo contrario, es posible que el comando no se ejecute correctamente.
